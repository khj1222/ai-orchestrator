# 검색 인터페이스 규격 (protocol v1)

두 검색 방법은 새 알고리즘이 아니라 통합·평가 흐름을 시험하기 위한 단순 기준 방법이다(03 §4). 이 문서의 모든 값은 확정이며, 해석이 갈리는 부분은 §8의 손계산 예시가 기준이다.

## 1. 모듈과 함수

| 항목 | 값 |
|---|---|
| 방법 A 모듈 | `methods/a.py` (`from methods import a`) |
| 방법 B 모듈 | `methods/b.py` (`from methods import b`) |
| 패키지 파일 | `methods/__init__.py` (내용은 비어 있어도 됨) |
| 함수 | 두 모듈 모두 `search(query, documents, k)` |
| 의존성 | Python 3.10 표준 라이브러리만. 모듈 import 시 부수 효과(파일 읽기, 출력) 없음 |
| 상태 | 없음. 같은 입력이면 항상 같은 출력. 난수·시각·환경 변수를 쓰지 않음 |

검색 모듈은 `data/`나 `queries.jsonl`의 `relevant_doc_ids`를 읽지 않는다. 문서는 인수로만 받는다.

## 2. 인수

| 인수 | 형 | 규칙 |
|---|---|---|
| `query` | `str` | 어떤 문자열이든 허용. 빈 문자열·공백만인 문자열도 오류가 아니다(§6) |
| `documents` | `list[dict]` | 각 원소는 `doc_id`(str)·`text`(str) 키를 가진 dict. 다른 키가 있으면 무시한다. 빈 목록 허용 |
| `k` | `int` | `0 <= k`. `bool`은 `int`의 하위형이지만 허용하지 않는다 |

## 3. 오류 (모두 `ValueError`)

- `k`가 `int`가 아니거나 `bool`이거나 `k < 0`.
- `query`가 `str`이 아님.
- `documents`가 list가 아니거나, 원소가 dict가 아니거나, `doc_id`·`text`가 없거나 `str`이 아님.
- `doc_id`가 목록 안에서 중복.

오류 검사는 계산 전에 전부 수행한다. 오류 시 부분 결과를 돌려주지 않는다.

## 4. 토큰화

```python
def tokens(s: str) -> set[str]:
    return set(s.lower().split())
```

- `str.lower()`(유니코드 소문자화) 뒤 `str.split()`(인수 없음: 연속된 유니코드 공백을 구분자로, 앞뒤 공백 제거).
- 구두점은 떼지 않는다. `"방법."`과 `"방법"`은 다른 토큰이다. 한국어 조사가 붙은 `"원두는"`과 `"원두"`도 다른 토큰이다. 형태소 분석·어간 추출·유니코드 정규화는 하지 않는다(자료가 NFC로 저장돼 있다고 가정한다). 이 제한은 보고서에 그대로 적는다.
- 반복 토큰은 집합이므로 한 번만 센다.

질의 토큰 집합을 Q, 문서 `text`의 토큰 집합을 D라 한다.

## 5. 점수

| 방법 | 점수 | 반환 형 |
|---|---|---|
| A | `len(Q & D)` | `int` |
| B | `len(Q & D) / len(Q | D)`. 단 `len(Q | D) == 0`이면 `0.0` | `float` (Python `/` 나눗셈, 반올림하지 않음) |

정렬 키는 `(-score, doc_id)`: 점수 내림차순, 같은 점수는 `doc_id` 오름차순(문자열 비교). 점수가 0이어도 순위에 포함한다.

## 6. 반환

- 정렬된 목록의 앞에서 `min(k, len(documents))`개를 돌려준다. 길이는 정확히 그 값이다.
- 원소는 `{"doc_id": str, "score": int | float}` dict. 이 두 키만 둔다. `doc_id`는 입력 문자열 그대로.
- `documents`가 비었거나 `k == 0`이면 `[]`.
- `query`의 토큰이 없으면(빈 문자열, 공백만) 모든 문서의 점수는 A `0`, B `0.0`이고, 반환은 `doc_id` 오름차순 앞 `min(k, n)`개다. 오류가 아니다.
- 반환 목록 안에 같은 `doc_id`는 두 번 나올 수 없다(입력에서 중복을 오류로 거르므로 자연히 보장된다).
- 입력 `documents` 목록과 dict를 수정하지 않는다.

## 7. 호출 규약 (실행기 쪽)

실행기는 두 모듈을 `from methods import a, b`로 import하고 질의마다 `a.search(text, documents, k)`, `b.search(text, documents, k)`를 호출한다. 실행기는 결과를 다시 정렬하거나 자르지 않고 받은 순서와 길이를 그대로 기록한다(raw-results.md). 실행기는 `ValueError`를 잡아 숨기지 않는다.

## 8. 손계산 예시 (구현과 검증기의 기준)

문서:

```
d001 "사과 바나나 사과"     → D = {사과, 바나나}
d002 "바나나 우유"          → D = {바나나, 우유}
d003 "포도"                 → D = {포도}
```

**예시 1.** `query = "사과 바나나 주스"`, Q = {사과, 바나나, 주스}, `k = 2`

| doc | Q∩D | Q∪D | A | B |
|---|---|---|---|---|
| d001 | {사과, 바나나} = 2 | {사과, 바나나, 주스} = 3 | 2 | 2/3 = 0.6666666666666666 |
| d002 | {바나나} = 1 | {사과, 바나나, 주스, 우유} = 4 | 1 | 1/4 = 0.25 |
| d003 | ∅ = 0 | {사과, 바나나, 주스, 포도} = 4 | 0 | 0/4 = 0.0 |

- A 반환: `[{"doc_id": "d001", "score": 2}, {"doc_id": "d002", "score": 1}]`
- B 반환: `[{"doc_id": "d001", "score": 0.6666666666666666}, {"doc_id": "d002", "score": 0.25}]`

**예시 2 (동점).** `query = "우유"`, `k = 3`

A 점수: d001 0, d002 1, d003 0. 정렬 → d002(1), d001(0), d003(0). 반환 `[d002, d001, d003]` 순. 0점끼리는 ID 오름차순이다.

**예시 3 (k가 문서 수보다 큼).** 예시 1의 질의에 `k = 10` → 3개만 반환(`min(10, 3)`), 순서는 d001, d002, d003.

**예시 4 (빈 질의).** `query = "   "`, `k = 2` → A `[{"doc_id": "d001", "score": 0}, {"doc_id": "d002", "score": 0}]`, B는 같은 순서에 `0.0`.

**예시 5 (합집합이 빔).** `query = ""`, `documents = [{"doc_id": "d001", "text": ""}]`, `k = 1` → B `[{"doc_id": "d001", "score": 0.0}]` (0으로 나누지 않는다).

**예시 6 (반복 토큰).** `query = "사과 사과 사과"`, Q = {사과}. d001은 A 1, B 1/2 = 0.5 (D = {사과, 바나나}). 반복은 한 번만 센다.

**예시 7 (대소문자).** `query = "Apple apple"`, 문서 `text = "APPLE pie"` → Q = {apple}, D = {apple, pie}, A 1, B 0.5.

**예시 8 (오류).** `k = -1` → `ValueError`. `k = True` → `ValueError`. `documents = [{"doc_id": "d001", "text": "x"}, {"doc_id": "d001", "text": "y"}]` → `ValueError`.

## 9. 흔한 오구현 (검증기가 잡는 것)

- 질의와 무관하게 항상 같은 ID를 돌려줌(예: 입력 순서 앞 k개). 예시 1·2가 다른 순서를 요구하므로 실패한다.
- 동점을 입력 순서로 둠. 예시 2에서 d003이 d001보다 앞에 오면 실패.
- B에서 반복 토큰을 세거나 합집합 대신 문서 길이로 나눔. 예시 1·6에서 값이 달라진다.
- `k > n`에서 빈 항목을 채우거나 예외를 냄. 예시 3.
- 빈 질의를 오류로 처리. 예시 4.
